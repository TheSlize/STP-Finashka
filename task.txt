Задача
Java (ORM + Spring Boot), базы данных (MySQL), веб-программирование (HTML, CSS, JavaScript). Реализовать информационную систему «Библиотека» с веб-интерфейсом.
Имеются такие установленные начальные значения трёх параметров:
поле «издательство» – publishingHouse, сортировка по дате выдачи – по убыванию, период гистограмм – 14 дней;
Необходимый функционал: добавление книги, удаление книги, редактирование книги, поиск книги по различным параметрам, отдельный фильтр (сортировка) по дате выдачи книги (на Java или JavaScript), гистограмма количества выдач книг по дням (на JavaScript или Java), счётчик книг в таблице (на JavaScript или Java).
Параметры объекта «книга»: ID, название книги, издательство, дата выдачи книги студенту, ФИО студента, дата сдачи книги студентом в библиотеку.

В выборе между javascript и java отдавай предпочтение java.
