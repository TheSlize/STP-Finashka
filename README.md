# Информационная система "Автопарк"

Spring Boot 3.5 + Spring Data JPA (Hibernate) + MySQL + Thymeleaf (HTML/CSS).
Поиск, сортировка, счётчики и гистограмма написаны на Java.
JavaScript используется для всплывающей формы машины, подтверждения удаления и обновления страницы без перезагрузки после любого действия.

## Начальные значения параметров

| Параметр | Значение | Где используется |
|---|---|---|
| поле "марка" | `model` | имя поля в классе `Car`, столбец `model` |
| сортировка по году выпуска | по убыванию | при запуске таблица отсортирована по году выпуска, сначала новые |
| период гистограммы | 14 дней | при запуске гистограмма показывает последние 14 дней |

Сортировка и период меняются на странице, начальные значения лежат в
`src/main/java/ru/autopark/service/CarSearchCriteria.java`.

## Что нужно установить

* JDK 17-24 (Gradle 8.14 к сожалению не запустится на JDK 25+)
* MySQL 8

## Запуск

1. Укажите логин и пароль MySQL в `src/main/resources/application.properties` (по умолчанию `root` / `root`).
2. Запустите класс `ru.autopark.AutoparkApplication` или выполните `gradlew.bat bootRun`.
3. Откройте http://localhost:8080

При первом запуске в пустую таблицу добавятся 16 машин с датами постановки на учёт за последние три недели.

## Функционал

* **Добавление и редактирование** - кнопки "+ Добавить машину" и "Изменить" открывают всплывающую форму.
* **Удаление** - кнопка "Удалить" с подтверждением.
* **Поиск** по марке и ФИО владельца (по части строки, без учёта регистра). Условия можно комбинировать.
* **Фильтр по году выпуска и дате постановки на учёт** - интервалы "с" / "по", любую границу можно не заполнять.
* **Сортировка по году выпуска** - при запуске выставлена по убыванию. Также можно отсортировать по любому столбцу:
клик по заголовку, повторный клик меняет направление.
* **Счётчик машин в таблице** - карточка "Машин в таблице" и значок у заголовка таблицы, плюс счётчики по всей базе: всего машин и разных марок.
* **Гистограмма постановки на учёт по дням** - при запуске ставится период за последние 14 дней, его можно поменять в поле "Период, дней" (от 1 до 31).
Высота столбиков считается в `CarService.dailyRegistrations()`, рисуется через HTML/CSS.

Проверки формы: все поля обязательны, год выпуска от 1900 до текущего, дата постановки на учёт не в будущем и не раньше года выпуска.

## Структура

```
src/main/java/ru/autopark/
    AutoparkApplication.java       точка входа
    config/
        DataInitializer.java       начальные данные
    model/
        Car.java                   сущность "машина" (таблица cars)
    repository/
        CarRepository.java         доступ к БД
    service/
        CarService.java            добавление, изменение, удаление, поиск, статистика
        CarSearchCriteria.java     параметры поиска и сортировки
        CarSpecifications.java     условие WHERE по заполненным полям
        DayStat.java               столбик гистограммы
        FleetStats.java            счётчики
    web/
        CarController.java         обработка запросов
src/main/resources/
    application.properties         настройки MySQL
    templates/cars.html            страница
    static/css/style.css           стили
    static/js/car-dialog.js        всплывающая форма
    static/js/list.js              все действия без перезагрузки страницы
    static/img/car.png             иконка
```
