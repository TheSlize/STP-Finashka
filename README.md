# Информационная система "Библиотека"

Spring Boot 3.5 + Spring Data JPA (Hibernate) + MySQL + Thymeleaf (HTML/CSS).
Поиск, сортировка, счётчики и гистограмма написаны на Java.
JavaScript используется для всплывающей формы книги, подтверждения удаления и обновления страницы без перезагрузки после любого действия.

## Начальные значения параметров

| Параметр | Значение | Где используется |
|---|---|---|
| поле "издательство" | `publishingHouse` | имя поля в классе `Book`, столбец `publishing_house` |
| сортировка по дате выдачи | по убыванию | при запуске таблица отсортирована по дате выдачи, сначала новые |
| период гистограммы | 14 дней | при запуске гистограмма показывает последние 14 дней |

Сортировка и период меняются на странице, начальные значения лежат в
`src/main/java/ru/library/config/VariantParameters.java`.

## Что нужно установить

* JDK 17-24 (Gradle 8.14 не запускается на JDK 25+).
* MySQL 8.

## Запуск

1. Укажите логин и пароль MySQL в `src/main/resources/application.properties` (по умолчанию `root` / `root`).
2. Запустите класс `ru.library.LibraryApplication` или выполните `gradlew.bat bootRun`.
3. Откройте http://localhost:8080

При первом запуске в пустую таблицу добавятся 16 книг с датами за последние три недели.

## Функционал

* **Добавление и редактирование** - кнопки "+ Добавить книгу" и "Изменить" открывают всплывающую форму.
* **Удаление** - кнопка "Удалить" с подтверждением.
  После добавления, изменения и удаления поиск и сортировка сохраняются.
* **Поиск** по названию, издательству, ФИО студента (по части строки, без учёта регистра)
  и по состоянию (все / на руках / сданы). Условия можно комбинировать.
* **Фильтр по дате выдачи** - интервал дат и сортировка по дате выдачи
  (при запуске по убыванию).
* **Сортировка по любому столбцу** - клик по заголовку, повторный клик меняет направление.
* **Счётчик книг в таблице** - карточка "Книг в таблице" и значок у заголовка таблицы,
  плюс счётчики по всей базе: всего, на руках, сдано.
* **Гистограмма выдач по дням** - при запуске за последние 14 дней, период меняется
  в поле "Период, дней" (от 1 до 31). Высота столбиков считается
  в `BookService.dailyIssues()`, рисуется через HTML/CSS.
## Структура

```
src/main/java/ru/library/
    LibraryApplication.java        точка входа
    config/
        DataInitializer.java       начальные данные
    model/
        Book.java                  сущность "книга" (таблица books)
        LoanStatus.java            состояние выдачи для поиска
    repository/
        BookRepository.java        доступ к БД
    service/
        BookService.java           добавление, изменение, удаление, поиск, статистика
        BookSearchCriteria.java    параметры поиска и сортировки
        BookSpecifications.java    условие WHERE по заполненным полям
        DayStat.java               столбик гистограммы
        LibraryStats.java          счётчики
    web/
        BookController.java        обработка запросов
src/main/resources/
    application.properties         настройки MySQL
    application-h2.properties      профиль без MySQL
    templates/books.html           страница
    static/css/style.css           стили
    static/js/book-dialog.js       всплывающая форма
    static/js/list.js              все действия без перезагрузки страницы
    static/img/book.png            иконка
```
