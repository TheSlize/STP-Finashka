# Информационная система "Склад магазина техники"

Spring Boot 3.5 + Spring Data JPA (Hibernate) + Spring Security + MySQL + Thymeleaf (HTML/CSS).
Поиск, сортировка, счётчики и гистограмма написаны на Java.
JavaScript используется для всплывающей формы техники, подтверждения удаления и обновления страницы без перезагрузки после любого действия.

## Начальные значения параметров

| Параметр | Значение | Где используется |
|---|---|---|
| поле "вид техники" | `type` | имя поля в классе `Equipment`, столбец `type` |
| сортировка по дате ввоза | по убыванию | при запуске таблица отсортирована по дате ввоза на склад, сначала новые |
| период гистограммы | 14 дней | при запуске гистограмма показывает последние 14 дней |

Сортировка и период меняются на странице, начальные значения лежат в
`src/main/java/ru/warehouse/service/EquipmentSearchCriteria.java`.

## Что нужно установить

* JDK 17-24 (Gradle 8.14 к сожалению не запустится на JDK 25+)
* MySQL 8

## Запуск

1. Укажите логин и пароль MySQL в `src/main/resources/application.properties` (по умолчанию `root` / `root`).
2. Запустите класс `ru.warehouse.WarehouseApplication` или выполните `gradlew.bat bootRun`.
3. Откройте http://localhost:8080 и войдите под пользователем `admin` / `admin` (или зарегистрируйте нового).

При первом запуске создаётся пользователь `admin`, а в пустую таблицу добавятся 16 единиц техники с датами за последние три с половиной недели (11 уже вывезены, 5 на складе).

## Авторизация

* Все страницы, кроме входа и регистрации, доступны только после входа.
* **Вход** - `/login`, при неверном логине или пароле выводится ошибка.
* **Регистрация** - `/register`: логин (3-50 символов, латиница, цифры, `_ . -`), пароль (от 4 символов) и его повтор. Занятый логин не пройдёт.
* **Выход** - кнопка "Выйти" в шапке, рядом показан логин текущего пользователя.
* Пароли хранятся в БД в виде хэша BCrypt (таблица `users`), формы защищены CSRF-токеном.

## Функционал

* **Добавление и редактирование** - кнопки "+ Добавить технику" и "Изменить" открывают всплывающую форму.
* **Удаление** - кнопка "Удалить" с подтверждением.
* **Поиск** по виду техники, группе техники, ФИО водителя (по части строки, без учёта регистра) и по состоянию (все / на складе / вывезена). Условия можно комбинировать.
* **Фильтр по дате ввоза** - интервал дат "с" / "по", любую границу можно не заполнять.
* **Сортировка по дате ввоза** - при запуске выставлена по убыванию. Также можно отсортировать по любому столбцу:
клик по заголовку, повторный клик меняет направление.
* **Счётчик записей в таблице** - карточка "Записей в таблице" и значок у заголовка таблицы, плюс счётчики по всей базе: всего, на складе, вывезено.
* **Гистограмма вывоза (отгрузки) техники по дням** - считается по дате вывоза. При запуске ставится период за последние 14 дней, его можно поменять в поле "Период, дней" (от 1 до 31).
Высота столбиков считается в `EquipmentService.dailyShipments()`, рисуется через HTML/CSS.

Проверки формы: все поля, кроме даты вывоза, обязательны; даты не в будущем; дата вывоза не раньше даты ввоза.
Пустая дата вывоза означает, что техника ещё на складе.

## Структура

```
src/main/java/ru/warehouse/
    WarehouseApplication.java         точка входа
    config/
        DataInitializer.java          начальные данные и пользователь admin
        SecurityConfig.java           настройки входа и выхода
    model/
        AppUser.java                  пользователь (таблица users)
        Equipment.java                сущность "техника" (таблица equipment)
        StockStatus.java              состояние (на складе / вывезена) для поиска
    repository/
        EquipmentRepository.java      доступ к технике
        UserRepository.java           доступ к пользователям
    service/
        EquipmentService.java         добавление, изменение, удаление, поиск, статистика
        EquipmentSearchCriteria.java  параметры поиска и сортировки
        EquipmentSpecifications.java  условие WHERE по заполненным полям
        UserService.java              загрузка пользователя для входа, регистрация
        DayStat.java                  столбик гистограммы
        WarehouseStats.java           счётчики
    web/
        EquipmentController.java      обработка запросов по технике
        AuthController.java           страницы входа и регистрации
        RegistrationForm.java         поля формы регистрации
src/main/resources/
    application.properties            настройки MySQL
    templates/equipment.html          главная страница
    templates/login.html              вход
    templates/register.html           регистрация
    static/css/style.css              стили
    static/js/equipment-dialog.js     всплывающая форма
    static/js/list.js                 все действия без перезагрузки страницы
    static/img/box.png                иконка
```
