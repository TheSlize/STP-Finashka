# Информационная система "Кинотеатр"

Spring Boot 3.5 + Spring Data JPA (Hibernate) + Spring Security + MySQL + Thymeleaf (HTML/CSS).
Поиск, сортировка, счётчики и гистограмма написаны на Java.
JavaScript используется для всплывающей формы сеанса, подтверждения удаления и обновления страницы без перезагрузки после любого действия.

## Начальные значения параметров

| Параметр | Значение | Где используется |
|---|---|---|
| поле "киностудия" | `filmStudio` | имя поля в классе `FilmSession`, столбец `film_studio` |
| сортировка по дате сеанса | по убыванию | при запуске таблица отсортирована по дате и времени сеанса, сначала поздние |
| период гистограммы | 14 дней | при запуске гистограмма показывает последние 14 дней |

Сортировка и период меняются на странице, начальные значения лежат в
`src/main/java/ru/cinema/service/FilmSessionSearchCriteria.java`.

## Что нужно установить

* JDK 17-24 (Gradle 8.14 к сожалению не запустится на JDK 25+)
* MySQL 8

## Запуск

1. Укажите логин и пароль MySQL в `src/main/resources/application.properties` (по умолчанию `root` / `root`).
2. Запустите класс `ru.cinema.CinemaApplication` или выполните `gradlew.bat bootRun`.
3. Откройте http://localhost:8080 и войдите под пользователем `admin` / `admin` (или зарегистрируйте нового).

При первом запуске создаётся пользователь `admin`, а в пустую таблицу добавятся 16 сеансов с датами за последние три недели.

## Авторизация

* Все страницы, кроме входа и регистрации, доступны только после входа.
* **Вход** - `/login`, при неверном логине или пароле выводится ошибка.
* **Регистрация** - `/register`: логин (3-50 символов, латиница, цифры, `_ . -`), пароль (от 4 символов) и его повтор. Занятый логин не пройдёт.
* **Выход** - кнопка "Выйти" в шапке, рядом показан логин текущего пользователя.
* Пароли хранятся в БД в виде хэша BCrypt (таблица `users`), формы защищены CSRF-токеном.

## Функционал

* **Добавление и редактирование** - кнопки "+ Добавить сеанс" и "Изменить" открывают всплывающую форму.
* **Удаление** - кнопка "Удалить" с подтверждением.
* **Поиск** по названию фильма и киностудии (по части строки, без учёта регистра). Условия можно комбинировать.
* **Фильтр по дате сеанса и количеству билетов** - интервалы "с" / "по" и "от" / "до", любую границу можно не заполнять.
* **Сортировка по дате сеанса** - при запуске выставлена по убыванию. Также можно отсортировать по любому столбцу:
клик по заголовку, повторный клик меняет направление.
* **Счётчик сеансов в таблице** - карточка "Сеансов в таблице" и значок у заголовка таблицы, плюс счётчики по всей базе: всего сеансов, киностудий, билетов.
* **Гистограмма сеансов по дням** - при запуске ставится период за последние 14 дней, его можно поменять в поле "Период, дней" (от 1 до 31).
Высота столбиков считается в `FilmSessionService.dailySessions()`, рисуется через HTML/CSS.

Проверки формы: все поля обязательны, количество билетов от 1 до 1000.

## Структура

```
src/main/java/ru/cinema/
    CinemaApplication.java              точка входа
    config/
        DataInitializer.java            начальные данные и пользователь admin
        SecurityConfig.java             настройки входа и выхода
    model/
        AppUser.java                    пользователь (таблица users)
        FilmSession.java                сущность "сеанс" (таблица film_sessions)
    repository/
        FilmSessionRepository.java      доступ к сеансам
        UserRepository.java             доступ к пользователям
    service/
        FilmSessionService.java         добавление, изменение, удаление, поиск, статистика
        FilmSessionSearchCriteria.java  параметры поиска и сортировки
        FilmSessionSpecifications.java  условие WHERE по заполненным полям
        UserService.java                загрузка пользователя для входа, регистрация
        DayStat.java                    столбик гистограммы
        CinemaStats.java                счётчики
    web/
        FilmSessionController.java      обработка запросов по сеансам
        AuthController.java             страницы входа и регистрации
        RegistrationForm.java           поля формы регистрации
src/main/resources/
    application.properties              настройки MySQL
    templates/sessions.html             главная страница
    templates/login.html                вход
    templates/register.html             регистрация
    static/css/style.css                стили
    static/js/session-dialog.js         всплывающая форма
    static/js/list.js                   все действия без перезагрузки страницы
    static/img/film.png                 иконка
```
